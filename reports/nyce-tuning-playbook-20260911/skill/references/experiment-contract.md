# 试验与数据约定

## 比较对象

原始F(5 ms)、假设延迟后的单点、持续力带、位置到位误差、最大回摆互不替代。当前回摆优先，欠跟/后摆/保持电流/力仍独立展示。用户接受±5%和2.5 ms补充口径后，不擅自加严或修改评分制造成功。

回摆用固定窗口内在前峰值到后续谷值的最大退回，例如0..25 ms；另列首次峰谷、目标下欠量、5..25 ms RMS、第二次摆动。简单max(x)−min(x)会混入上升行程。下压为正画图，CSV保留原生符号。0.1 µm/125 µs对应0.8 mm/s速度格点，不是独立的机械突跳证据；居中拟合斜率标注窗宽、非实时性质。

## 执行前与有限轮次

fresh核对状态、raw位置/SP、原点、预压、速度、频率和必要配置。重复对照尽量不在中途慢调/重置/改接触条件；必要时分新阶段。

冻结配方hash、完整增益、节点相位、保持返回、起点、预算、主指标、候选数及停止条件。预算包含有符号基线/全部FF/反馈余量，覆盖主段、保持、返回；它不等于实际跟踪或电流保证。

正常、故障、取消和运输中断均保留恢复记录；先分类再决定下一步。已有授权覆盖常规恢复或新阶段时，在适用边界内推进，不为每个可逆步骤重复求许可。

| 现象 | 区分与处理 |
|---|---|
| 原生FE/CF_FE/206 | 跟踪失败，核FF和状态；首故障后不评正常性能 |
| 218结束超时 | 复算回程连续资格，检查静态FF失配、积分残余；不等同5 ms上升失败 |
| COMPLETE但保持SD超线 | 事后健康筛选停止，不改成轴故障、不抹停止理由 |
| 预压/静止/交接拒绝，无派发 | 0实际运动，不计作实测性能 |
| SSH或主机读失败 | 用意图、raw和库核实是否已派发，不盲目重发 |
| 1 ULP边界 | 用工程分辨率及有依据容差修复校验，不扩大物理范围 |
| 测力同值平台 | 同步展示位置/电流/计数；延迟平移不能解释或消除平台 |

## 时变增益需验证什么

- 前40/后60拍定义一致；不能5 ms末撤销而漏掉5～10 ms回摆。
- 平滑入口/退出、幅值与每拍增量约束；用少量参数生成全表，避免直接任意调100×多增益。
- 记录请求/返回/参数读回/actual gain及写前写后相位；守护比较预期曲线。
- 缺省禁用时旧JSON字节、ID和运行行为保持；新通道或协议不得误解析旧记录。
- KI切换是否保留、缩放或清零积分状态需独立证据；未确认前固定KI。
- 离线插值/单位/预算/异常恢复通过后，再有限真实扰动；收益候选冻结复测，接触条件变化重验。

## 保全

请求、真实动作、成功/失败/拒绝、真实行数和库归属分列。原生FE不等于同排SP−x。原始时钟、旧失败、闭合阶段不重写；新评价另存并注明口径。完整实验组合包含实际反馈，参数下载不等于异机可直接运行。
